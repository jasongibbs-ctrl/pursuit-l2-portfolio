# Jason Gibbs Portfolio

Modern, responsive personal portfolio for Jason Gibbs featuring:

- Home introduction
- About Me background in luxury retail operations, inventory management, and AI/software development
- Projects showcase (SATT Outreach Agent, Day Off Planner, Slack Clone, Depop Shipping Redesign, TileBar Inventory Dashboard)
- Skills section
- Resume download (PDF)
- Contact links (GitHub, LinkedIn, email)

## Tech Stack

- HTML
- CSS
- JavaScript

## Local Setup

1. Clone the repository.
2. From the project root, install metadata scaffold (already included):
   ```bash
   npm install
   ```
3. Start a local server:
   ```bash
   npm start
   ```
4. Open `http://localhost:4173`.

## Deployment

This is a static site and can be deployed on any static host.

### GitHub Pages

1. Push changes to your repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your default branch and root folder (`/`).
5. Save and wait for the Pages URL to become available.
